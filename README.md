## 项目

### [Free Car Control](./free-car-control/)

基于嵌入式视觉与电机闭环控制的智能车项目，包含图像处理、赛道边线/误差计算、速度决策、双轮速度环 PID、陀螺仪补偿以及相关嵌入式依赖库。

- 主要语言：C/C++、Shell
- 主要方向：嵌入式系统、计算机视觉、运动控制
- 当前方案：速度决策 + 图像差速 + 角速度补偿 + 双轮速度闭环
- 项目说明：[free-car-control/README.md](./free-car-control/README.md)
