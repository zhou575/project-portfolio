# Project Portfolio



## 项目

### [Free Car Control](./free-car-control/)

基于嵌入式视觉与电机闭环控制的智能车项目，包含图像处理、赛道边线/误差计算、速度决策、双轮速度环 PID、陀螺仪补偿，以及轻量级图像分类模型的训练、评估和部署流程。

- 主要语言：C/C++、Shell
- 主要语言：C/C++、Python、Shell
- 主要方向：嵌入式系统、计算机视觉、轻量级模型训练与部署、运动控制
- 当前方案：速度决策 + 图像差速 + 角速度补偿 + 双轮速度闭环
- 模型分类：supplies、vehicle、weapon；提供 PyTorch、ONNX 和 NCNN 文件

- 模型训练说明：[free-car-control/model-training/README.md](./free-car-control/model-training/README.md)
